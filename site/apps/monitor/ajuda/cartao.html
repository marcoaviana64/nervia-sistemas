Manual completo

O roteador de cada local mede os links de internet a cada minuto e manda para a Nervia. Aqui você vê se está tudo no ar, quando caiu, por quanto tempo, e a disponibilidade do mês para cobrar a operadora.

Equipamentos EQUIPE NERVIA

+ Novo local · editarLocal (endereço do cliente) e nome do cliente.
quem vêLogins do cliente que veem o local. O login também precisa do app liberado em Administração → Logins.
+ Novo equipamento · editarNome, modelo, local e se está ativo.
gerar scriptCria o token do roteador e o script para colar no Terminal. Gerar de novo troca o token.
Links (nome=host de teste)Um por linha; host de teste diferente para cada link (ex.: 8.8.8.8, 1.1.1.1).
Nome do linkAbre o cadastro: nome, operadora, contratado, host de teste, meta do contrato, latência de alerta, ordem, monitorar.
anotar (na queda)Registra protocolo, causa ou combinado com a operadora. O cliente vê.
